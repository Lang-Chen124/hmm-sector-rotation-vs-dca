# Generated results

Running the notebooks creates output directories that are intentionally excluded from version control.

## CSI 300 DCA notebook

`沪深300定投基准收益.ipynb` creates `baseline_outputs/`, containing files such as:

- `csi300_dca_daily.csv` — daily account value, contributions, profit and drawdown;
- `csi300_dca_trades.csv` — monthly purchases;
- performance and annual summary exports generated by the notebook.

## HMM sector-rotation notebook

`HMM市场状态与申万一级行业轮动策略.ipynb` creates `hmm_sw_rotation_outputs/`, including:

- `monthly_signals.csv` — signal dates, state probabilities, selected industries and target weights;
- `strategy_daily.csv` — daily strategy account and time-weighted NAV;
- `strategy_trades.csv` — monthly rebalances and turnover;
- `benchmark_dca_daily.csv` and `benchmark_dca_trades.csv` — aligned benchmark records;
- `performance_metrics.csv` — headline absolute metrics;
- `relative_metrics.csv` — beta, alpha approximation, tracking error and information ratio;
- `annual_summary.csv` — calendar-year results;
- `industry_coverage.csv` — available-history diagnostics for each industry.

## Why outputs are not committed

These files can be regenerated from the notebooks and may depend on updated upstream data. Excluding them keeps the repository focused and avoids presenting stale generated data as a canonical dataset.

Selected results from the saved notebook run are summarised in the root [README](../README.md).
